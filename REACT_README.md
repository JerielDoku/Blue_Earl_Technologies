# Blue Earl Technologies - React Web App

A modern React-based web application for Blue Earl Technologies - Innovation for Essential Industries.

## Project Structure

```
src/
├── components/
│   ├── Navigation.js    # Main navigation component with mobile support
│   └── Footer.js        # Footer component
├── pages/
│   ├── Home.js          # Homepage with hero section
│   ├── Services.js      # Services page
│   ├── About.js         # About page
│   ├── Contact.js       # Contact form page
│   ├── Insights.js      # Insights blog page
│   ├── Investing.js     # Investing page
│   └── industries/      # Industry-specific pages
│       ├── Healthcare.js
│       ├── RealEstate.js
│       ├── PrivateEducation.js
│       ├── Food.js
│       ├── Manufacturing.js
│       ├── Logistics.js
│       ├── ProfessionalServices.js
│       └── CoreServices.js
├── styles/
│   └── index.css        # Main stylesheet
├── App.js               # Main app component with routing
└── index.js             # React entry point
public/
└── index.html           # HTML entry point
package.json             # Project dependencies and scripts
```

## Installation

1. Navigate to the project directory:
```bash

```

2. Install dependencies:
```bash
npm install
```

## Available Scripts

### `npm start`
Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm run build`
Builds the app for production to the `build` folder.

### `npm test`
Launches the test runner in interactive watch mode.

## Features

- **Responsive Design**: Mobile-first approach with responsive navigation
- **Multiple Industry Pages**: Dedicated solutions for 8 different industries
- **Services Showcase**: Highlight of Blue Earl's core services
- **Contact Form**: Fully functional contact form with industry selection
- **Modern UI**: Clean, professional design with color-coded sections
- **Accessibility**: Built with accessibility best practices
- **Fast Navigation**: React Router for client-side routing

## Technologies Used

- **React 18.2.0**: UI library
- **React Router DOM 6.16.0**: Client-side routing
- **Lucide React 0.292.0**: Icon library
- **CSS3**: Styling with CSS custom properties

## Deployment

To deploy this application:

1. Build the production version:
```bash
npm run build
```

2. Deploy the `build` folder to your hosting service (Vercel, Netlify, GitHub Pages, etc.)
